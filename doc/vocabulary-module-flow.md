# 背单词模块完整业务流程文档

## 1. 模块定位

背单词模块是 IvyEd 主程序中的一个功能模块，不是独立 App。主程序负责提供入口、用户身份、课程/文章/笔记等素材来源；背单词模块负责把学习目标拆成可执行任务，并围绕单词完成学习、练习、反馈、复习、评测和任务再生成。

模块第一版以 `Word` 为核心学习对象，但底层按 `LearningItem` 设计，未来可以扩展到短语、句型、语法点、听力片段、阅读生词、写作表达、口语句子和错题。

## 2. 设计框架

背单词模块基于六个核心能力：

| 框架 | 含义 | 在模块中的落点 |
| --- | --- | --- |
| 任务驱动 | 把长期目标拆成每日可完成任务 | 目标、水平、强度、偏好 -> 学习计划 -> 今日任务 |
| 场景承载 | 单词绑定真实学习/使用场景 | 考试、商务、日常、阅读、课程生词、AI 生成词库 |
| 学习对象 | 每个词都是可调度、可反馈、可复习对象 | `LearningItem` + `UserLearningItemState` |
| 记忆算法 | 根据表现动态安排复习 | `masteryScore`、答对次数、错词次数、`nextReviewAt` |
| 学习反馈 | 每次操作都有正误和错因反馈 | 练习反馈、错因标签、强化建议 |
| 评测分析 | 用报告和测试反向调整计划 | 阶段测试、学习报告、计划调整 |

## 3. 核心闭环

完整闭环必须保持如下顺序：

```text
进入模块
-> 目标设定
-> 场景 / 素材选择
-> 词库选择或生成
-> 学习计划生成
-> 今日任务
-> 新词学习
-> 即时练习
-> 学习反馈
-> 错词处理
-> 间隔复习
-> 阶段测试
-> 学习报告
-> 计划调整
-> 下一轮任务生成
```

关键原则：

- 首次用户不能直接进入今日任务，必须先完成目标、场景、词库和计划。
- 今日任务不是静态列表，而是由计划、错词、复习队列和测试周期共同生成的学习控制台。
- 答错不是简单记录，而是进入错词强化和复习调度。
- 学习报告不是终点，而是下一轮任务生成的输入。

## 4. 用户完整路径

### 4.1 首次使用路径

1. 用户从首页、学习中心、课程生词、AI 推荐等入口进入背单词模块。
2. 系统判断用户是否登录、是否存在 `VocabularyProfile`、是否已有当前学习计划。
3. 若未初始化，进入目标设定页。
4. 用户选择学习目标、水平、强度和偏好。
5. 系统推荐场景和词库方向。
6. 用户选择学习场景与素材来源。
7. 用户确认词库或生成词库。
8. 系统创建学习计划，初始化学习对象状态。
9. 系统生成今日任务。
10. 用户开始今日学习。

### 4.2 已初始化用户路径

1. 用户进入背单词模块。
2. 系统检查今日任务是否已生成。
3. 若未生成，根据学习计划、错词、复习队列生成任务。
4. 用户进入今日任务页。
5. 用户可以开始新词学习、进入复习、强化错词、查看报告或调整计划。

## 5. 阶段流程

### 阶段 1：进入模块

用户动作：
- 点击背单词入口。
- 等待模块加载。
- 首次使用时开始初始化。
- 非首次使用时查看今日任务。

系统动作：
- 判断登录状态。
- 判断是否有 `VocabularyProfile`。
- 判断是否有当前 `StudyPlan`。
- 判断今日任务是否已生成。
- 首次使用跳转目标设定。
- 非首次使用进入今日任务。

页面功能：
- 模块入口。
- 加载状态。
- 首次使用引导。
- 今日任务入口。

数据沉淀：
- 用户模块状态。
- 是否完成初始化。
- 当前学习计划 ID。
- 当前词库 ID。
- 今日任务状态。

### 阶段 2：目标设定

用户动作：
- 选择学习目标：四六级、考研、雅思、托福、商务英语、日常英语、阅读提升、课程学习、自定义目标。
- 选择当前水平。
- 设置每日学习强度。
- 选择学习偏好：记忆、拼写、听力、例句、考试、阅读理解、口语表达、商务表达。

系统动作：
- 根据目标推荐学习场景。
- 根据目标推荐词库。
- 根据当前水平设置初始难度。
- 根据强度计算每日新词和复习上限。
- 根据偏好调整题型比例。
- 生成初始计划草案。

页面功能：
- 目标选择表单。
- 水平选择。
- 强度选择。
- 偏好选择。
- 推荐说明。
- 生成计划按钮。

数据沉淀：
- 学习目标。
- 当前水平。
- 每日学习强度。
- 学习偏好。
- 初始学习计划草案。
- 推荐词库记录。

### 阶段 3：场景与素材选择

用户动作：
- 选择学习场景：考试备考、商务沟通、日常口语、学术阅读、新闻阅读、课程学习、旅行交流、自定义场景。
- 选择素材来源。
- 确认系统推荐，或上传/选择自己的学习素材。

素材来源：
- 官方词库。
- 考试词库。
- 用户自定义词库。
- 主程序文章生词。
- 主程序课程生词。
- 用户笔记生词。
- AI 根据目标生成词库。
- 用户手动导入单词表。

系统动作：
- 根据目标匹配推荐场景。
- 根据场景推荐素材来源。
- 提取文章、课程、笔记中的生词。
- 根据目标和场景生成 AI 词表。
- 给学习对象绑定场景标签和来源信息。
- 进入词库确认流程。

页面功能：
- 场景选择卡片。
- 素材来源选择。
- 推荐词库说明。
- 内容生词提取入口。
- AI 生成词库入口。
- 用户导入入口。

数据沉淀：
- 学习场景。
- 素材来源。
- 场景标签。
- 生词来源记录。
- AI 生成词库记录。
- 用户导入记录。

### 阶段 4：词库选择或生成

用户动作：
- 查看推荐词库。
- 选择词库。
- 查看词库详情。
- 确认使用词库。
- 可选调整词库范围。

词库类型：
- 官方词库：基础词汇、核心词汇、高频词汇。
- 考试词库：四六级、考研、雅思、托福。
- 自定义词库：用户手动添加。
- 内容生词本：文章、课程、笔记中提取。
- AI 生成词库：根据目标和场景自动生成。

系统动作：
- 加载词库数据。
- 初始化用户词库进度。
- 标记每个学习对象初始状态。
- 绑定词库、场景和来源信息。
- 准备生成学习计划。

页面功能：
- 词库列表。
- 词库分类。
- 词库详情。
- 单词总量。
- 难度说明。
- 预计完成时间。
- 使用该词库按钮。

数据沉淀：
- 用户词库关系。
- 用户词库进度。
- 学习对象初始状态。
- 词库来源。
- 场景标签。

### 阶段 5：学习计划生成

学习计划是首次初始化中不可省略的独立阶段，不能隐藏在今日任务页中。

系统输入：
- 用户目标。
- 当前水平。
- 每日学习强度。
- 学习偏好。
- 场景。
- 词库。
- 词库规模和难度。

系统输出：
- `StudyPlan`。
- 每日新词数。
- 每日复习上限。
- 阶段测试周期。
- 预计完成时间。
- 题型比例。
- 首轮任务生成规则。

页面功能：
- 学习计划预览。
- 每日任务量确认。
- 题型偏好确认。
- 阶段测试周期展示。
- 确认生成今日任务。

数据沉淀：
- 学习计划 ID。
- 计划版本。
- 计划生成原因。
- 预计完成日期。
- 测试周期。

### 阶段 6：今日任务页

今日任务页是学习控制台。

页面展示：
- 今日新词数量。
- 今日复习数量。
- 今日错词强化数量。
- 今日测试任务。
- 预计学习时间。
- 已学单词。
- 已掌握单词。
- 待复习单词。
- 易错单词。
- 总词库完成度。
- 当前学习场景。
- AI 学习建议。

用户动作：
- 查看今日任务。
- 开始今日学习。
- 继续上次学习。
- 复习错词。
- 查看词库。
- 查看报告。
- 调整计划。

系统动作：
- 根据计划生成今日新词。
- 根据 `nextReviewAt` 生成今日复习词。
- 根据错词记录生成错词强化任务。
- 根据测试周期判断是否安排测试。
- 生成学习建议。
- 计算预计学习时间。

数据沉淀：
- 今日任务记录。
- 任务状态。
- 任务生成原因。
- 任务完成度。
- 建议记录。

### 阶段 7：新词学习

每组学习建议为 10 到 20 个学习对象。

单词卡片内容：
- 单词。
- 音标。
- 发音。
- 中文释义。
- 英文释义。
- 例句。
- 例句翻译。
- 场景标签。
- 素材来源。
- 词根词缀。
- 近义词。
- 反义词。
- 常见搭配。
- AI 记忆法。

用户操作：
- 认识。
- 模糊。
- 不认识。
- 收藏。
- 加入错词本。
- 查看更多解释。

系统动作：
- 展示当前学习组。
- 记录首次学习时间。
- 记录主观掌握度。
- 更新学习对象状态。
- 加入后续练习队列。
- 调整 `masteryScore`。

状态更新：
- 认识 -> `familiar`。
- 模糊 -> `weak`。
- 不认识 -> `learning`。

数据沉淀：
- 学习记录。
- 主观掌握度。
- 学习时间。
- 初始 `masteryScore`。
- 状态变化。
- 学习会话记录。

### 阶段 8：即时练习

用户完成一组新词后，系统进入即时练习。

MVP 题型：
- 看英文选中文。
- 看中文选英文。
- 拼写输入。

后续题型：
- 听音选词。
- 例句填空。
- 单词配对。
- 判断正误。

用户动作：
- 做题。
- 提交答案。
- 查看反馈。
- 继续下一题。
- 查看本组结果。

系统动作：
- 根据学习组生成练习题。
- 判断答案是否正确。
- 识别错误类型。
- 更新 `masteryScore`。
- 答错加入错词本。
- 答对进入复习队列。
- 生成本组结果。

练习结果：
- 本组正确率。
- 掌握单词数。
- 模糊单词数。
- 错误单词数。
- 建议复习时间。

数据沉淀：
- 答题记录。
- 正确率。
- 错误类型。
- 响应时间。
- 提示使用次数。
- 掌握度变化。
- 练习会话记录。

### 阶段 9：学习反馈

反馈贯穿新词学习、即时练习、复习和测试。

反馈内容：
- 是否正确。
- 正确答案。
- 错误类型。
- 简短解释。
- 对应场景例句。
- 后续系统处理方式。

错误类型：
- 完全不认识。
- 释义混淆。
- 拼写错误。
- 听音错误。
- 语境错误。
- 反向回忆失败。

系统动作：
- 判断错误类型。
- 生成简短解释。
- 绑定错因标签。
- 决定是否加入错词本。
- 决定是否安排专项强化。
- 更新掌握度。

数据沉淀：
- 错误类型。
- 错因标签。
- 反馈查看记录。
- 是否查看更多解释。
- 是否进入强化任务。

### 阶段 10：错词处理

答错的学习对象自动进入错词本，并进入强化机制。

错误类型与强化方式：
- 完全不认识 -> 重新学习单词卡片。
- 释义混淆 -> 近义词辨析。
- 拼写错误 -> 拼写训练。
- 听音错误 -> 听音训练。
- 语境错误 -> 例句填空。

用户动作：
- 查看错词本。
- 查看错误原因。
- 进行错词复测。
- 进行专项强化。
- 查看是否已掌握。

系统动作：
- 自动收集错词。
- 合并重复错词记录。
- 更新错误次数。
- 记录错误类型。
- 安排强化任务。
- 判断是否可以移出错词本。

移出规则：
- 连续答对 2 到 3 次。
- 掌握度达到系统阈值。
- 最近一次复测通过。

数据沉淀：
- 错词记录。
- 错因历史。
- 错误次数。
- 错词状态。
- 错词复测结果。

### 阶段 11：间隔复习

复习优先级：

```text
错词 > 即将遗忘词 > 今日到期词 > 新学词 > 已掌握词抽查
```

基础规则：
- 第一次学会：短时间后复习。
- 答对且反应快：延长复习间隔。
- 答对但反应慢：保持或轻微延长间隔。
- 答错：缩短复习间隔。
- 连续答错：重新进入学习流程。
- 多次稳定答对：标记为 `mastered`。

用户动作：
- 进入今日复习。
- 完成复习题。
- 查看复习反馈。
- 查看复习结果。

系统动作：
- 查询今日到期复习词。
- 按优先级排序。
- 生成复习题。
- 更新 `nextReviewAt`。
- 更新 `currentIntervalDays`。
- 更新 `masteryScore`。
- 判断是否 `mastered`。

数据沉淀：
- 复习计划。
- `lastReviewedAt`。
- `nextReviewAt`。
- `currentIntervalDays`。
- 复习正确率。
- 掌握度变化。

### 阶段 12：阶段测试

触发条件：
- 每学习 100 个词。
- 每 7 天。
- 每完成一个词库单元。
- 考试前冲刺。
- 用户手动发起。

测试内容：
- 识别测试。
- 反向测试。
- 听力测试。
- 拼写测试。
- 语境测试。
- 综合测试。

系统动作：
- 抽取已学词、弱词和错词。
- 生成混合测试题。
- 计算总分。
- 计算正确率和掌握率。
- 识别薄弱词和薄弱题型。
- 生成下一阶段建议。

数据沉淀：
- 测试结果。
- 测试题记录。
- 正确率。
- 掌握率。
- 薄弱词。
- 薄弱题型。
- 阶段能力变化。

### 阶段 13：学习报告、计划调整与下一轮任务

报告类型：
- 今日报告：学习时长、新学数、复习数、错词数、正确率、任务完成度。
- 周报告：学习天数、新增掌握词、遗忘率变化、高频错词、薄弱题型、学习稳定性。
- 总体报告：总词汇量、已掌握量、待复习量、错词总量、词库完成度、长期记忆稳定度、趋势曲线。

计划调整输入：
- 学习报告。
- 错词情况。
- 复习负荷。
- 阶段测试结果。
- 用户手动偏好调整。

系统动作：
- 判断新词量是否过高或过低。
- 判断复习负荷是否过重。
- 判断错词是否过多。
- 调整明日任务。
- 调整题型比例。
- 调整阶段测试周期。
- 生成下一轮任务。

数据沉淀：
- 学习统计。
- 正确率趋势。
- 掌握率趋势。
- 错词趋势。
- 任务完成趋势。
- 计划版本。
- 调整原因。
- 调整前后任务。
- 用户是否接受调整。

## 6. 数据流转总览

| 阶段 | 输入 | 输出 |
| --- | --- | --- |
| 进入模块 | 用户模块状态 | 是否首次使用、跳转目标 |
| 目标设定 | 目标、水平、强度、偏好 | 学习计划草案 |
| 场景与素材选择 | 学习目标、场景、素材来源 | 词库候选、场景标签 |
| 词库选择 | 词库数据 | 用户词库进度、学习对象初始状态 |
| 学习计划生成 | 用户画像、场景、词库 | `StudyPlan` |
| 今日任务 | 词库状态、错词记录、复习计划 | `DailyVocabularyTask` |
| 新词学习 | 主观掌握判断 | 单词状态、`masteryScore` |
| 即时练习 | 答题记录 | 掌握度、错词记录、复习计划 |
| 学习反馈 | 错误类型 | 错因标签、强化任务 |

## 8. 状态流转

正常学习：

```text
new -> learning -> familiar -> reviewing -> mastered
```

答错：

```text
learning / reviewing -> wrong -> weak -> reviewing -> mastered
```

已掌握后再次答错：

```text
mastered -> weak -> reviewing
```

连续多次答错：

```text
weak / wrong -> learning
```

连续多次答对：

```text
reviewing -> mastered
```

## 12. 接入主程序原则

主程序只做引导，不把背单词流程塞回首页。

入口可以来自：
- 首页今日学习任务。
- 学习中心。
- 英语学习页面。
- 课程生词入口。
- 个人学习计划。
- AI 助手推荐。

入口行为：
- 若 `VocabularyProfile.initialized === false`，进入 `/vocabulary/onboarding`。
- 若已有 profile 但缺少场景，进入 `/vocabulary/scenario`。
- 若已有场景但缺少词库，进入 `/vocabulary/books`。
- 若已有词库但未生成计划，进入 `/vocabulary/plan`。
- 若计划完整，进入 `/vocabulary` 今日任务页。

## 13. 验收标准

- 首次用户能完整走完目标、场景、词库、计划、今日任务。
- 非首次用户进入后能直接看到今日任务。
- 今日任务由计划、错词、复习队列生成，不是写死数据。
- 新词学习后必须进入即时练习。
- 答错必须产生反馈、错词记录和复习调度。
- 答对必须更新掌握度和复习计划。
- 报告必须能反向影响计划调整。
- 所有页面有空状态。
- Mock 数据能支撑完整演示。
- 代码实现保持页面、组件、状态、数据和算法分层。
