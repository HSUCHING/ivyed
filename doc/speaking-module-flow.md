# 口语学习模块完整业务流程文档

## 1. 模块定位

口语学习模块是 IvyEd 英文学习主程序中的功能模块，负责把用户的口语目标拆成可执行任务，并围绕口语学习对象完成输入准备、跟读模仿、自由表达、即时反馈、错因强化、间隔复练、阶段测评和计划调整。

它不是单纯的“录音打分”功能，而是一个面向口语能力增长的任务闭环。系统需要帮助用户决定今天练什么、在哪个场景下练、用什么素材练、如何反馈、如何复练，以及下一轮任务如何生成。

## 2. 设计框架

口语学习同样基于六个核心能力：

| 框架 | 含义 | 口语模块中的落点 |
| --- | --- | --- |
| 任务驱动 | 把长期口语目标拆成每日任务 | 目标、水平、强度、偏好 -> 口语计划 -> 今日口语任务 |
| 场景承载 | 口语练习绑定真实表达场景 | 日常对话、考试口语、商务会议、课堂展示、旅行问答、面试沟通 |
| 学习对象 | 每个表达单元都可学习、练习、反馈、复练 | `SpeakingItem` / `LearningItem` |
| 记忆算法 | 对薄弱表达、发音问题、语法错误安排复练 | `masteryScore`、错误次数、复练时间、表达熟练度 |
| 学习反馈 | 对发音、流利度、词汇、语法、内容结构即时反馈 | 录音反馈、错因标签、强化建议 |
| 评测分析 | 通过报告和阶段测评反向调整口语计划 | 口语评分、维度趋势、薄弱场景、下一轮任务 |

## 3. 核心闭环

```text
进入口语模块
-> 目标设定
-> 场景 / 素材选择
-> 口语学习对象生成
-> 口语学习计划生成
-> 今日口语任务
-> 输入准备
-> 跟读 / 模仿
-> 自由表达 / 角色对话
-> 即时反馈
-> 薄弱项强化
-> 间隔复练
-> 阶段测评
-> 学习报告
-> 计划调整
-> 下一轮口语任务生成
```

关键原则：

- 首次用户不能直接进入录音页，必须先确定目标、场景、素材和计划。
- 口语学习对象不是只有句子，也可以是短语、话题、问答、情景对话、表达模板、语音片段。
- 反馈不能只给一个总分，必须拆成发音、流利度、词汇、语法、内容、互动六类维度。
- 薄弱项必须回流到复练任务，而不是停留在报告里。

## 4. 用户完整路径

### 4.1 首次使用路径

1. 用户从首页、学习中心、课程学习、AI 推荐或今日任务进入口语模块。
2. 系统判断是否登录、是否存在 `SpeakingProfile`、是否已有当前口语计划。
3. 若未初始化，进入目标设定。
4. 用户选择口语目标、当前水平、每日练习强度和练习偏好。
5. 系统推荐口语场景和素材来源。
6. 用户选择场景、素材和练习类型。
7. 系统生成口语学习对象与学习计划。
8. 系统生成今日口语任务。
9. 用户开始输入准备、跟读模仿和自由表达。
10. 系统给出反馈，并安排薄弱项复练。

### 4.2 已初始化用户路径

1. 用户进入口语模块。
2. 系统检查今日口语任务是否已生成。
3. 若未生成，根据计划、薄弱项和复练队列生成任务。
4. 用户进入今日口语任务页。
5. 用户可以开始练习、复练薄弱项、查看报告、进入阶段测评或调整计划。

## 5. 阶段流程

### 阶段 1：进入模块

用户动作：
- 点击口语学习入口。
- 等待模块加载。
- 首次使用时开始初始化。
- 非首次使用时查看今日口语任务。

系统动作：
- 判断登录状态。
- 判断是否有 `SpeakingProfile`。
- 判断是否有当前 `SpeakingPlan`。
- 判断今日口语任务是否已生成。
- 首次使用跳转目标设定。
- 非首次使用进入今日任务。

数据沉淀：
- 用户口语模块状态。
- 是否完成初始化。
- 当前口语计划 ID。
- 当前口语场景 ID。
- 今日任务状态。

### 阶段 2：目标设定

用户动作：
- 选择学习目标：日常口语、考试口语、商务英语、面试沟通、课堂展示、旅行交流、演讲表达、自定义目标。
- 选择当前水平：入门、基础、进阶、熟练、考试冲刺。
- 设置每日练习强度。
- 选择练习偏好：偏发音、偏流利度、偏词汇表达、偏语法准确、偏内容组织、偏互动问答、偏考试评分。

系统动作：
- 根据目标推荐口语场景。
- 根据水平设置初始难度。
- 根据强度计算每日任务量。
- 根据偏好调整练习类型比例。
- 生成初始口语计划草案。

数据沉淀：
- 口语目标。
- 当前水平。
- 每日练习强度。
- 练习偏好。
- 初始计划草案。

### 阶段 3：场景与素材选择

学习场景：
- 日常对话。
- 考试口语。
- 商务会议。
- 课堂展示。
- 旅行交流。
- 面试沟通。
- 新闻讨论。
- 课程复述。
- 自定义场景。

素材来源：
- 官方口语题库。
- 考试话题库。
- 课程材料。
- 文章/视频内容。
- 用户笔记。
- AI 生成情景对话。
- 用户自定义题目。

系统动作：
- 根据目标匹配推荐场景。
- 根据场景推荐素材来源。
- 从课程、文章、笔记提取可复述素材。
- 使用 AI 生成情景对话、问答和表达模板。
- 给每个口语学习对象绑定场景标签和来源。

数据沉淀：
- 场景选择。
- 素材来源。
- 场景标签。
- 素材引用。
- AI 生成记录。

### 阶段 4：口语学习对象生成

口语学习对象类型：
- 单句表达。
- 常用短语。
- 情景问答。
- 对话片段。
- 话题卡。
- 表达模板。
- 复述材料。
- 影子跟读音频。
- 用户错句。

系统动作：
- 将素材拆成 `SpeakingItem`。
- 标注难度、场景、目标能力和练习方式。
- 生成参考表达、关键词、示例回答和评分维度。
- 初始化用户状态。

数据沉淀：
- `SpeakingItem`。
- 学习对象来源。
- 初始状态。
- 能力维度标签。

### 阶段 5：口语学习计划生成

系统输入：
- 用户目标。
- 当前水平。
- 每日练习强度。
- 练习偏好。
- 场景。
- 素材。
- 学习对象数量和难度。

系统输出：
- 每日输入准备量。
- 每日跟读任务量。
- 每日自由表达任务量。
- 每日复练上限。
- 阶段测评周期。
- 预计完成时间。
- 评分维度权重。

数据沉淀：
- `SpeakingPlan`。
- 计划版本。
- 计划生成原因。
- 测评周期。
- 预计完成日期。

### 阶段 6：今日口语任务

今日任务包括：
- 输入准备。
- 跟读 / 模仿。
- 自由表达。
- 场景角色对话。
- 薄弱项复练。
- 阶段测评。

系统动作：
- 根据计划生成今日新任务。
- 根据薄弱项记录生成强化任务。
- 根据复练时间生成到期复练任务。
- 判断是否安排阶段测评。
- 生成今日口语建议。

数据沉淀：
- `DailySpeakingTask`。
- 任务状态。
- 任务生成原因。
- 任务完成度。
- 建议记录。

### 阶段 7：输入准备

用户动作：
- 阅读场景说明。
- 听参考音频。
- 查看关键词、句型和表达模板。
- 理解示例回答和语境。

系统动作：
- 展示输入材料。
- 标注重点表达。
- 给出发音提示。
- 加入后续练习队列。

数据沉淀：
- 输入查看记录。
- 重点表达曝光记录。
- 用户准备时长。

### 阶段 8：跟读 / 模仿

用户动作：
- 听标准音频。
- 跟读录音。
- 重复练习。
- 查看发音反馈。

系统动作：
- 采集录音。
- 对齐参考音频。
- 评估发音、重音、语调、节奏。
- 标注薄弱音素或表达片段。
- 决定是否需要重复跟读。

数据沉淀：
- 录音记录。
- 发音评分。
- 音素/重音/语调错误。
- 重复次数。

### 阶段 9：自由表达 / 角色对话

用户动作：
- 根据话题自由表达。
- 按角色完成对话。
- 回答追问。
- 可选查看提示。

系统动作：
- 记录表达内容。
- 转写语音为文本。
- 评估词汇、语法、流利度、内容结构和互动回应。
- 判断是否完成任务。

数据沉淀：
- 录音。
- 转写文本。
- 回答耗时。
- 提示使用次数。
- 表达完整度。

### 阶段 10：即时反馈

反馈维度：
- 发音准确度。
- 语调与重音。
- 流利度。
- 词汇丰富度。
- 语法准确度。
- 内容组织。
- 场景适配度。
- 互动回应。

错误类型：
- 发音错误。
- 重音错误。
- 语调不自然。
- 卡顿过多。
- 词汇不足。
- 语法错误。
- 内容偏题。
- 回答结构弱。
- 场景表达不合适。

系统动作：
- 生成总分和维度分。
- 生成错因标签。
- 给出更自然表达。
- 标注需要复练的句子或片段。
- 决定是否进入薄弱项强化。

数据沉淀：
- `SpeakingPracticeRecord`。
- 评分维度。
- 错因标签。
- 修正建议。
- 薄弱项标记。

### 阶段 11：薄弱项强化

强化方式：
- 发音错误 -> 音素与最小对立练习。
- 重音/语调错误 -> 跟读和节奏训练。
- 卡顿过多 -> 关键词复述训练。
- 词汇不足 -> 替换表达训练。
- 语法错误 -> 错句重说。
- 内容结构弱 -> 模板化回答训练。
- 场景不适配 -> 场景表达替换训练。

移出规则：
- 连续 2 到 3 次达标。
- 维度分达到阈值。
- 阶段测评通过。

数据沉淀：
- `WeakSpeakingRecord`。
- 错因历史。
- 强化任务。
- 复练结果。
- 是否解决。

### 阶段 12：间隔复练

复练优先级：

```text
薄弱项 > 即将遗忘表达 > 今日到期复练 > 新学表达 > 已掌握表达抽查
```

系统动作：
- 查询到期复练对象。
- 根据薄弱维度排序。
- 生成复练任务。
- 更新 `nextPracticeAt`。
- 更新 `masteryScore` 和维度分。
- 判断是否 mastered。

数据沉淀：
- 复练计划。
- `lastPracticedAt`。
- `nextPracticeAt`。
- 当前间隔天数。
- 掌握度变化。

### 阶段 13：阶段测评

触发条件：
- 每完成 7 天练习。
- 每完成一个场景单元。
- 每完成一定数量口语对象。
- 考试冲刺。
- 用户手动发起。

测评内容：
- 跟读测评。
- 话题表达。
- 角色对话。
- 追问回答。
- 复述任务。
- 综合表达。

系统动作：
- 抽取已练、薄弱和到期复练对象。
- 生成混合测评。
- 计算总分和维度分。
- 识别薄弱场景、薄弱表达和薄弱能力维度。
- 生成下一阶段建议。

数据沉淀：
- 测评结果。
- 评分维度。
- 薄弱项。
- 阶段能力变化。

### 阶段 14：学习报告、计划调整与下一轮任务

报告类型：
- 今日报告：练习时长、完成任务数、录音次数、维度评分、薄弱项数量、任务完成度。
- 周报告：练习天数、平均评分、流利度趋势、发音错误趋势、高频薄弱表达。
- 总体报告：总练习时长、已掌握表达、薄弱场景、综合口语能力趋势。

计划调整：
- 判断任务量是否过高或过低。
- 判断某个维度是否持续薄弱。
- 调整跟读、自由表达、角色对话和复练比例。
- 调整阶段测评周期。
- 生成下一轮口语任务。

数据沉淀：
- `SpeakingReport`。
- 评分趋势。
- 薄弱趋势。
- 计划版本。
- 调整原因。
- 下一轮任务。

## 7. 核心数据对象

- `SpeakingProfile`：用户口语学习画像。
- `SpeakingScenario`：口语学习场景。
- `SpeakingMaterialSource`：口语素材来源。
- `SpeakingItem`：口语学习对象，底层可复用 `LearningItem`。
- `SpeakingPlan`：口语学习计划。
- `UserSpeakingItemState`：用户对口语对象的掌握状态。
- `DailySpeakingTask`：每日口语任务。
- `SpeakingPracticeRecord`：口语练习记录。
- `WeakSpeakingRecord`：薄弱项记录。
- `SpeakingAssessmentResult`：阶段测评结果。
- `SpeakingReport`：学习报告。

## 8. 状态流转

正常学习：

```text
new -> preparing -> shadowing -> speaking -> reviewing -> mastered
```

出现薄弱项：

```text
shadowing / speaking / reviewing -> weak -> reinforced -> reviewing -> mastered
```

已掌握后退化：

```text
mastered -> weak -> reviewing
```

连续多次未达标：

```text
weak -> preparing
```

## 10. 验收标准

- 首次用户必须完整走完目标、场景、素材、学习对象和计划。
- 今日任务由计划、薄弱项和复练队列生成。
- 口语练习必须有录音、转写、维度评分和错因标签。
- 薄弱项必须生成专项强化任务。
- 间隔复练必须根据表现更新 `nextPracticeAt`。
- 阶段测评必须产出维度分析。
- 学习报告必须能反向影响计划调整。
- Mock 数据能支撑完整演示流程。
