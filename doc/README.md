# IvyEd Docs

This folder contains product and architecture diagrams for the IvyEd learning app.

## Diagrams

- [Vocabulary Learning Module Business Flow](./vocabulary-business-flow.html)
  - Full business logic flow for the vocabulary module.
  - Covers task-driven onboarding, scenario/material selection, word book selection, plan generation, daily task execution, practice, feedback, wrong-word handling, spaced review, testing, report, and plan adjustment.
  - Open directly in a browser.

- [Speaking Learning Module Business Flow](./speaking-module-flow.html)
  - Full business logic flow for the speaking module.
  - Covers goal onboarding, scenario/material selection, speaking item generation, plan generation, daily task execution, input preparation, shadowing, free speaking, feedback, weakness reinforcement, spaced practice, assessment, report, and plan adjustment.
  - Open directly in a browser.
