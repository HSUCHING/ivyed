流程内容

主程序入口进入模块

  • 入口：首页今日任务 / 学习中心 / 英语学习页 / 课程生词 / 个人计划 / AI 推荐。
  • 系统先判断用户是否已经完成背词计划初始化。
是：今日任务页 / 否：目标设定

用户动作

  • 点击背单词入口。
  • 等待模块加载。
  • 首次使用时开始初始化。
  • 非首次使用时查看今日任务。

系统动作

  • 检查登录状态。
  • 检查 `VocabularyProfile`。
  • 检查当前 `StudyPlan`。
  • 检查今日任务是否已生成。

数据沉淀

  • 模块状态。
  • 初始化状态。
  • 当前计划 ID。
  • 当前词库 ID。
  • 今日任务状态。

目标、水平、强度、偏好

  • 学习偏好：记忆、拼写、听力、例句、考试、阅读理解、口语表达、商务表达。

流程内容

单词先绑定场景，再进入词库

  • 学习场景：考试、商务、日常口语、学术阅读、新闻阅读、课程学习、旅行交流、自定义。
  • 素材来源：官方词库、考试词库、自定义词库、文章生词、课程生词、笔记生词、AI 生成、导入表。

流程内容

学习一组新词

  • 每组建议 10 到 20 个 LearningItem。
  • 单词卡包含音标、发音、释义、例句、场景、来源、词根词缀、近反义、搭配、AI 记忆法。
认识 -> familiar模糊 -> weak不认识 -> learning

  • 收藏或加入错词本。

流程内容

即时反馈与后续处理

  • 反馈内容：是否正确、正确答案、错误类型、简短解释、场景例句、后续处理。
  • 错误类型：不认识、释义混淆、拼写错误、听音错误、语境错误、反向回忆失败。
是：错词处理 / 否：复习调度

用户动作

  • 查看反馈。
  • 理解错因。
  • 继续下一题。
  • 可选查看更多解释。

系统动作

  • 判断错误类型。
  • 生成解释。
  • 绑定错因标签。
  • 决定是否进入错词本。
  • 安排强化任务。

数据沉淀

  • 错误类型。
  • 错因标签。
  • 反馈查看记录。
  • 强化任务标记。

流程内容

错词进入强化机制

  • 不认识 -> 重新学习卡片。
  • 释义混淆 -> 近义词辨析。
  • 拼写错误 -> 拼写训练。
  • 听音错误 -> 听音训练。
  • 语境错误 -> 例句填空。
移出规则：连续答对 2 到 3 次，或掌握度达阈值，或最近一次复测通过。

用户动作

  • 查看错词本。
  • 查看错误原因。
  • 进行错词复测。
  • 进行专项强化。

系统动作

  • 自动收集错词。
  • 合并重复记录。
  • 更新错误次数。
  • 记录错误类型。
  • 判断是否解决。

数据沉淀

  • `WrongItemRecord`。
  • 错因历史。
  • 错误次数。
  • 复测结果。
  • resolved 状态。

流程内容

间隔复习与状态流转

  • 优先级：错词 > 即将遗忘词 > 今日到期词 > 新学词 > 已掌握词抽查。
  • 答对延长间隔，答错缩短间隔，连续答错回到学习流程，稳定答对标记掌握。
new->learning->familiar->reviewing->mastered
错词回流：wrong -> weak -> reviewing -> mastered。

用户动作

  • 进入今日复习。
  • 完成复习题。
  • 查看复习反馈。
  • 查看复习结果。

系统动作

  • 查询到期复习词。
  • 按优先级排序。
  • 生成复习题。
  • 更新 `nextReviewAt`。
  • 更新 `masteryScore`。

数据沉淀

  • 复习计划。
  • `lastReviewedAt`。
  • `nextReviewAt`。
  • 间隔天数。
  • 掌握度变化。

流程内容

阶段测试触发与评测分析

  • 触发：每学习 100 个词、每 7 天、完成一个单元、考试冲刺、用户手动发起。
  • 内容：识别、反向、听力、拼写、语境、综合测试。
总分正确率掌握率薄弱词薄弱题型

  • 查看测试结果。

系统动作

  • 抽取已学词、弱词、错词。
  • 生成混合测试。
  • 计算分数。
  • 识别薄弱项。
  • 生成建议。

数据沉淀

  • 测试结果。
  • 测试题记录。
  • 掌握率。
  • 薄弱词。
  • 能力变化。

流程内容

学习报告反向调整计划

  • 报告：今日报告、周报告、总体报告。
  • 计划调整：判断新词量、复习负荷、错词压力、题型比例和测试周期。
报告不是终点，报告是下一轮任务生成的输入。
