流程内容

反馈必须拆成维度，而不是只给总分

  • 维度：发音准确度、语调重音、流利度、词汇、语法、内容组织、场景适配、互动回应。
  • 错因：发音错误、卡顿、词汇不足、语法错误、内容偏题、结构弱、场景表达不合适。
是：薄弱项强化 / 否：间隔复练

流程内容

薄弱项回流为专项强化任务

  • 发音错误 -> 音素与最小对立练习；重音/语调错误 -> 跟读和节奏训练。
  • 卡顿过多 -> 关键词复述；词汇不足 -> 替换表达；语法错误 -> 错句重说。
  • 内容结构弱 -> 模板化回答；场景不适配 -> 场景表达替换。
移出规则：连续 2 到 3 次达标，或维度分达到阈值，或阶段测评通过。

用户动作

  • 查看薄弱项。
  • 查看错误原因。
  • 完成专项复练。
  • 查看复练结果。

系统动作

  • 合并重复错因。
  • 生成强化任务。
  • 记录复练结果。
  • 判断是否解决。
  • 回流复练队列。

数据沉淀

  • `WeakSpeakingRecord`。
  • 错因历史。
  • 强化任务。
  • 复练结果。
  • resolved 状态。

流程内容

按表现安排下一次复练

  • 优先级：薄弱项 > 即将遗忘表达 > 今日到期复练 > 新学表达 > 已掌握表达抽查。
  • 系统根据薄弱维度排序，更新 `nextPracticeAt`、`masteryScore` 和维度分。
new->preparing->shadowing->speaking->reviewing->mastered
薄弱回流：shadowing / speaking / reviewing -> weak -> reinforced -> reviewing -> mastered。

用户动作

  • 进入到期复练。
  • 完成复练任务。
  • 查看复练反馈。
  • 查看掌握变化。

系统动作

  • 按薄弱维度排序。
  • 生成复练任务。
  • 更新下次练习时间。
  • 判断是否 mastered。

数据沉淀

  • 复练计划。
  • `lastPracticedAt`。
  • `nextPracticeAt`。
  • 间隔天数。
  • 掌握度变化。
